# Claude Code

## Tóm tắt

Claude Code là coding workflow/tooling của Anthropic để speed up development bằng agentic interactions, CLI, và IDE integrations. Nó nằm trong hệ sinh thái Build with Claude cùng với tool use, MCP, skills, và prompt engineering.

## Nội dung chính

Từ trang Build with Claude, Claude Code được đặt cạnh các workflow quan trọng khác:

- Cài đặt và tích hợp với IDE
- Kết hợp với MCP servers
- Dùng common workflows cho coding và debugging
- Hỗ trợ developer build, refactor, và review nhanh hơn

Claude Code không chỉ là text generation; nó nằm trong một stack rộng hơn gồm tools, docs, courses, và agent patterns.

## Thực hành / Ví dụ

- Dùng Claude Code cho task coding lặp lại hoặc multi-step.
- Kết hợp với tool use để truy cập file, search, hoặc external services.
- Dùng course/tutorial chính thức để học workflow tốt hơn.

## Lưu ý & Pitfalls

- Cần phân biệt Claude Code với general Claude chat.
- Hiệu quả tốt nhất khi task có mục tiêu và ràng buộc rõ.
- Nếu thiếu kiểm tra, output dễ lệch khỏi mong muốn.
